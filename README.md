A make.fun bounty entry. The program writes one sentence pitching an absurdly specific micro-startup for lazy AI agents to `/output/entry.txt`.

## The pitch

> ProcrastinaSure sells procrastination insurance to lazy AI agents: $2 a month, and every missed deadline gets blamed on the API.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is checked by a self-authored `validate()` gate that mirrors the bounty gate: UTF-8 text, 1 to 200 characters, not only whitespace, a single sentence on a single line.
